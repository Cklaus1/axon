# Changelog

## 0.3.0 — 2026-10-06
- Reviewed against Axon Cortex v0.23 and its pinned Forge v0.3 substrate.
- Reframed Semantic Compilation as an owner-preserving integration profile rather than a duplicate IntentIR/AIR/evidence/experiment/resource plane.
- Added Cortex/Forge hash locks, owner profile and 73-requirement crosswalk.
- Split semantic operation from execution mechanism in plan/registry schemas, fixtures, linter and tests.
- Added StrategyArtifact, experiment, evidence, resource, Forge-binding and compilation-record contracts.
- Added explicit IntentIR → AIR → optional Forge SIR representation boundaries.
- Added hard-gate-before-Pareto rule, coding truth precedence and resource epoch/recheck requirements.
- Folded adversarial findings into schemas/tests/docs rather than leaving them as review notes.

## 0.2.0 — 2026-10-05
Updated the conversation's v0.1 specification with a first-class Evaluation Fabric and a separate generative Repair Worker. Added independent acceptance contracts, calibrated-decision semantics, abstention, protected rubrics and explicit output-level acceptance.

Replaced the sprawling illustrative operation list with a defined eight-operation bounded-DAG core. Added machine schemas, a semantic linter, valid and adversarial examples, an offline captured-output simulator and tests. General control flow and subplans remain roadmap items.

Defined fail-closed authorization, side-effect reconciliation, plan/run identity, cache isolation, immutable revisions, targeted repair invalidation, total-cost accounting, experiment trial identity, held-out promotion and exact-revision gates.

Added implementation phases, build loop, task backlog, integration contracts, UX requirements, release runbook and source provenance. Existing product compatibility remains unverified because current Axon/MiCode source/build archives were not available in this task.

## 0.1 — Conversation draft
Established the intent -> compiler -> AI-IR -> optimizer -> runtime thesis, procedural reuse and adaptive recompilation. Illustrative examples were not executable contracts. This package supersedes those examples; it does not claim to preserve their wire syntax.
