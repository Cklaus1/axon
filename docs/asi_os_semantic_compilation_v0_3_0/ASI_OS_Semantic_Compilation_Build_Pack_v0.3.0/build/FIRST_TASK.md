# First Implementation Task

Implement the smallest real **document transformation or local test-repair** path in the existing repository. Do not begin with an autonomous optimizer or a universal OS rewrite.

## Task for the coding agent
Read AGENTS and the integration plan. Inspect the current repository and write a real module/type mapping for intent, run/trial IDs, artifacts, policy, config and telemetry. Choose one task family with an independently checkable result. Bind the v0.3 contracts to the existing Cortex owners; do not create a second IntentIR, AIR, capability registry, evidence graph, experiment store or resource authority. Add admission that rejects malformed graphs, unknown capabilities and unauthorized requests. Connect one compiler adapter and one isolated execution path. Run the exact output through a protected deterministic criterion. Record the full trace and actual usage.

Keep external publishing, messaging, payments, exploration and auto-promotion disabled. The initial compiler emits one candidate; repair is at most one approved round. The typed judge is optional until deterministic acceptance works. Do not claim Jev or Axon integration without exercising the actual adapters.

## Required proof
Show a good input passing and an intentionally bad output failing; show an unauthorized capability being blocked before dispatch; show the final artifact digest matching acceptance evidence; show a budget/timeout failure ending without new calls. Run existing repository gates against the frozen final HEAD.

## Definition of done
A reviewed module mapping, one real end-to-end task, negative-path tests, source/config/artifact digests and a report listing unimplemented milestones. No public deployment is requested by this task.
