# Strategy, Evidence, Experiments, and Resource Projections

## StrategyArtifact
Every experimentable compiler, repair, evaluator, router, retrieval, plan-optimization, resource-placement, or software-transform strategy receives stable identity, version, parent lineage, configuration identity and implementation references. A prompt edit without a strategy identity is not valid causal/promotion evidence.

## Canonical experiments
Semantic Compilation may propose an experiment profile, but CX-33 owns the canonical experiment lifecycle in the Cortex profile. Hypothesis, falsifier, controlled mutation, evaluator, metrics, hard gates, corpus role and stopping rule are fixed before protected outcomes are inspected.

## Evidence
Compilation/evaluation/repair/build observations are projection payloads attached to CX-32 canonical evidence identities. Material effective inputs, environment, artifact versions, strategy identity and resource epoch remain traceable. A local experience row is useful telemetry but cannot replace evidence required by admission.

## Resources
Resource projections are observations, not reservations. They retain authoritative source and observation epoch. The scheduler/authority must recheck availability, grants and budget at protected dispatch.

## Ordering rule

```text
hard semantic / correctness / security / authority gates
                     ↓
              eligible candidates
                     ↓
       Pareto / utility / cost ranking
```

No scalar reward rescues an invalid candidate.
