# v0.3 Fold-In Summary

The v0.3 revision folds both the Cortex/Forge design review and the adversarial review into the package rather than leaving them as recommendations.

Implemented changes include: Cortex owner profile and hash locks; requirement-level Cortex crosswalk; explicit IntentIR/AIR/SIR layering; semantic-operation vs physical-mechanism separation in schemas, fixtures, linter and tests; StrategyArtifact, canonical experiment profile, evidence projection, resource projection, Forge binding and compilation-record schemas; new integration documentation; hard-gate-before-optimization rule; Forge truth-resolution and semantic-transform guidance; and new conformance tests for ownership/projection boundaries.

Additional adversarial fold-ins include an explicit AIR reference in Forge bindings, stale-owner-profile hash locking, projection-authority caveats, no build-success-to-effect inference, cache reauthorization requirements, and frozen experiment scorecards.
