# Changelog v0.15

## Added

- CX-32 Universal Evidence Graph and `build/UNIVERSAL_EVIDENCE_GRAPH.md`.
- CX-33 Causal and Active Experimentation Plane and `build/CAUSAL_ACTIVE_EXPERIMENTATION.md`.
- CX-34 Cognitive Scheduler and Shared Capability Registry and `build/COGNITIVE_SCHEDULER_REGISTRY.md`.
- B140–B151 work packages.
- G32/G33/G34 gate families.

## Architectural effect

The package now has an explicit connective substrate: evidence is traversable across all planes, causal improvement claims require intervention discipline, and heterogeneous cognitive capabilities are registered/admitted/scheduled through one OS-like dispatch layer. Self-improvement remains outside protected kernel authority and new capabilities cannot self-publish.
