# Schema / fixed-task Reflex fixtures — v0.20

Synthetic, model-free examples only. `records.json` binds a non-BMP Unicode source span, active Boolean and optional-presence questions, typed arguments, current registry/schema and a detached qualification identity. `experiment-template.json` is an unfilled preregistration draft, not measured evidence. No tool, model, teacher request, browser bridge or admission authority is executed.

The reference deliberately rejects arrays, nested schemas, references and unsupported constraints. It does not implement filesystem locks, network idempotency, full JSON Schema, OOD detection, signed releases or the live Axon ABI. The production tasks require those actual owner seams and their declared scope. Fixture JSON hashing is not `axon.cjson/1`.

Run `python -B -m unittest discover -s tests -p 'test_schema_reflex*.py' -v` from the package root. These tests cannot mark a product gate PASS.
