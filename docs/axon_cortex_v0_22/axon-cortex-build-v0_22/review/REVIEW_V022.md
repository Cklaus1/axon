## Remaining blockers (not papered over)

The sources still need the new real bridge/use sites, durable operation/reservation implementation, hardened physical profile qualification, runtime context/scope enforcement where missing, actual joint tests, policy adoption/rollback and a separately approved study. The pack delivers implementation requirements, not those runtime results. No protected profile, live policy or measured-improvement claim is enabled by this review.
