# CX-18 v0.23 Forge integration amendment — Forge artifact promotion

Repeatedly successful Transform, Migration, pipeline or backend strategies may become native compiler/runtime promotion candidates only through existing evidence/admission paths. Forge candidate identity and evidence are preserved across promotion; the candidate cannot judge or activate itself.

## v0.23 acceptance gates

**G18-r23-forge-promotion:** Forge transforms/migrations/pipelines become native promotion candidates only with independent evidence and existing CX-11/CX-18 admission; no Forge-local winner flag activates code.

**G18-r23-compiler-promotion:** A promoted compiler transform retains source Forge artifact lineage, rollback target and semantic/conformance requirements.
