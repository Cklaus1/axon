# Forge v0.3 Acceptance Checklist

- [ ] Source lowers to canonical SIR.
- [ ] Hard semantic/security invariants are represented and checked.
- [ ] Transform registration/application is schema-driven and attributable.
- [ ] Transform result emits semantic diff, diagnostics, verification requirements and provenance projection.
- [ ] Meta execution requests authority externally, defaults to deny and cannot mint grants.
- [ ] Meta/build execution binds to an external isolation/receipt seam.
- [ ] Compiler failures normalize to structured diagnostics.
- [ ] MiCode can perform compile -> diagnose -> repair using structured data.
- [ ] Truth resolver records current compiler/source/conformance evidence and conflicts.
- [ ] Bootstrap pack can teach a minimally-known frontend/toolchain.
- [ ] BuildProgram emits declared deterministic BuildGraph data.
- [ ] Semantic migration supports dry-run and idempotency expectation.
- [ ] Forge experiment data attaches to canonical Axon experiment identity.
- [ ] Forge evidence/provenance attaches to canonical CX-32 evidence identity.
- [ ] Resource model is explicitly a non-authoritative Fabric/CX-34 projection.
- [ ] Strategy profile references a canonical versioned StrategyArtifact.
- [ ] Faster but invariant-violating candidates are invalid.
- [ ] No duplicate experiment/evidence/capability/resource authority is introduced.
