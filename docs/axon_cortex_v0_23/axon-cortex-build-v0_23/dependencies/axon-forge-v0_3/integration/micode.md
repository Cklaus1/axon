# MiCode Integration

Preferred loop:

`bootstrap/truth context -> inspect source/SIR -> propose minimal transform/implementation -> verify -> compile -> consume structured diagnostics -> semantic repair -> targeted tests/benchmarks -> emit Forge evidence payload -> Axon experiment`

When language/API semantics are uncertain, MiCode SHOULD query current compiler/source/conformance evidence before model priors. Large repetitive changes SHOULD prefer a versioned `Migration` to thousands of independent text edits.
