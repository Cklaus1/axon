# Forge v0.3 -> Cortex v0.23 integration

The integration rule is **projection, not duplication**.

1. MiCode/Cortex selects or proposes a coding/compiler strategy.
2. Forge represents the program in SIR and applies bounded semantic operations.
3. Protected meta/build/compiler work requests CX-03 authority and executes through CX-13/Fabric.
4. Forge emits structured diagnostics, semantic diff and evidence payloads.
5. CX-32 records canonical evidence/provenance.
6. CX-33 compares incumbent/challenger under a frozen evaluator.
7. CX-11/CX-18 admit/promote or refuse; CX-29 may use the history to propose future strategy.

No arrow grants authority to the previous layer.
