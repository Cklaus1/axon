# docs/history — archived session & diagnostic docs

This folder holds **superseded, point-in-time** Markdown docs that were once at
the repo root: autonomous-loop driver prompts, one-time audits, and session
recaps. They are kept for provenance, not as current guidance.

For the **current, durable design** see:

- `governance/specs/` — the 18 active requirement specs (source of truth)
- `governance/REQUIREMENTS.md` — the requirement index and work queue
- `ROADMAP.md`, `CLAUDE.md`, `README.md` — entry-point docs at the repo root
- `BUILD_RESOLVED.md` — the canonical "how the native build works now" doc

- `AUTONOMOUS_BUILD_ALL.md` — loop prompt for building all of R3–R10 end-to-end (driver scratch).
- `AUTONOMOUS_MAX.md` — alternate "build at max quality" loop prompt (driver scratch).
- `MITOSIS_AUDIT.md` — one-time hand audit of the repo (2026-05-06), byproduct of the Mitosis tool design.
- `SESSION_RECAP.md` — point-in-time session recap (2026-05-05 → 05-06) of working-tree state and what to keep.
